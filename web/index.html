    How the Trading Signal Is Calculated

    Dashboard calculation

    The dashboard analyzes the latest 30 daily closing prices. It normalizes prices to the first close, fits a linear regression, and derives the vector angle as atan(β × 30).

    Intensity is |30-day return| × volume ratio ÷ daily volatility, where the volume ratio compares the average volume of the latest 3 days with the 30-day average. Confidence is min(100, intensity × R² × multiplier).

    BUY requires a positive angle and both the angle and intensity thresholds. SELL uses the same requirements with a negative angle. All other cases are HOLD.

    HP search and validation

    The Python research workflow uses Optuna's TPE sampler to evaluate strategy parameters: signal threshold, lookback, profit take, stop loss, maximum position, cash buffer, and trade threshold.

    It splits dates chronologically: the first 70% tunes parameters and the final 30% is held out for one validation run. The default optimization objective is total return; Sharpe and Calmar are also available. Results include each trial and the selected parameters.

    The HP parameters control the Python backtest strategy and are separate from this dashboard's three config.json signal settings.

    Tests

    Automated tests cover bullish and bearish threshold symmetry, parameter loading and validation, the HP search ranges and parameter mapping, previous-session windows, and portfolio allocation behavior.
